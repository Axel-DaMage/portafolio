# portafolio

Experimental personal portfolio for **inop1a** — FOSS builder, white-hat student, systems tinkerer, and multilingual technologist.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- pnpm

## Development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Quality gates

```bash
pnpm lint
pnpm format:check
pnpm build
```

## Deployment

The site is a static-friendly Next.js application and can be deployed to Vercel or any platform supporting Next.js.
